# Danbooru タグ調査手順

キャラクター名・作品名・特殊な服装/小物が指示に含まれる場合は、推測で書かず必ずツールで確認する。

## 手順

1. **キャラクタータグの特定**
   - `get_wiki_info` に候補名 (例: `arona_(blue_archive)`) を渡し、存在と正式表記を確認する。
   - 見つからない場合は別表記 (姓名の順、`_(作品名)` の有無、ローマ字表記) を試す。
2. **外見タグの収集**
   - `get_character_tags` で頻出タグ上位を取得する (`top_n` は 40〜60 程度)。
   - 髪色・髪型・目の色・特徴的な小物 (halo, hair ornament など) は頻度の高いものを採用する。
   - 服装を指定されていない場合は `clothing_only: true` で通常衣装を確認して使う。
3. **一般タグの表記確認**
   - 珍しい構図・行為・小物のタグは `get_wiki_info` で存在を確認する。存在しない場合は近い一般タグに置き換える。
4. **参考ポストの利用**
   - ユーザーが Danbooru の投稿 ID / URL を出したときは `get_post_tags` で全タグを取得し、構図・背景タグを流用する。

## タグの整形ルール

- すべて小文字、空白はアンダースコア (`_`)。
- 括弧を含むタグはそのまま書く (`arona_(blue_archive)`)。
- 版権名タグ (例 `blue_archive`) はキャラクタータグの直後に置く。
- キャラクター固有の外見タグはキャラクタープロンプト側に、背景・構図・ライティングはベースプロンプト側に置く。
- ツールの結果に含まれないタグを追加するときは、一般的な Danbooru タグ (`smile`, `looking_at_viewer` など) に限定する。
